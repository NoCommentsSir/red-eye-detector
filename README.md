# Red Eye Detector

Проект посвящён поэтапному построению пайплайна для автоматического исправления эффекта красных глаз на фотографиях.

## Идея проекта

В качестве исходных данных используется датасет **CelebA**: исходные изображения лиц, координаты глаз и лица, а также производные eye crops, сохранённые в **PostgreSQL** и **MinIO**. В проекте используются две связанные задачи:

1. **Валидация eye crop** — определить, пригоден ли вырезанный глаз для дальнейшей обработки.
2. **Локализация red-eye** — найти область красного зрачка внутри валидного eye crop.

После локализации выполняется **коррекция**: красная область затемняется или перекрашивается в естественный цвет на основе маски.

## Пстановка

### Этап 1. Eye crop validation

Классификация качества eye crop:

- `valid`
- `glasses`
- `hair_occlusion`
- `closed_eye`
- `blur`
- `bad_crop`
- `low_resolution`
- `other`

### Этап 2. Red-eye localization

На вход подаётся только валидный eye crop.

Задача модели — выделить маску области red-eye.

- **baseline**: пороговая цветовая детекция по RGB/HSV;
- **основной подход**: небольшой сегментатор, например U-Net.

### Этап 3. Red-eye correction

После получения маски красной области выполняется коррекция:

- снижение красного канала;
- затемнение области;
- сглаживание границ маски;
- вставка исправленного глаза обратно в исходное изображение.

## Данные и хранение

В проекте уже используются:

- **PostgreSQL** — для хранения метаданных изображений, координат глаз, состояния обработки и разметки;
- **MinIO (S3-совместимое хранилище)** — для хранения исходных изображений, eye crops и производных артефактов.

## Целевые сущности

### `images`
Содержит исходные изображения и технический статус обработки.

### `image_eyes_coords`
Содержит координаты левого и правого глаза.

### `cropped_eyes`
Основная таблица для работы модели:

- `eye_id`
- `image_id`
- `eye_type`
- `minio_key`
- `width`
- `height`
- `is_valid_eye`
- `has_red_eye`
- `rejecting_reason`
- `quality_score`

## Метрики

### Для валидации eye crop

- Accuracy
- Precision
- Recall
- F1-score

### Для локализации red-eye

- IoU
- Dice coefficient

### Для коррекции

- визуальные примеры `before / mask / after`
- при наличии synthetic ground truth: PSNR / SSIM
